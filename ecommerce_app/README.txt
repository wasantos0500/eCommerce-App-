# eCommerce Store Application

## Overview

This project is a Django-based eCommerce application developed as part of the HyperionDev Web Development Bootcamp.

The application demonstrates:

- User authentication
- Authorization using Groups
- Vendor and Buyer roles
- Store management
- Product management
- Shopping cart using Sessions
- Reviews
- Django Admin
- Relational database models

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS

## Installation

```bash
pip install django
python manage.py migrate
python manage.py runserver
```

## Features

- User Registration
- Login / Logout
- Vendor Dashboard
- Product Management
- Shopping Cart
- Reviews
- Password Reset
